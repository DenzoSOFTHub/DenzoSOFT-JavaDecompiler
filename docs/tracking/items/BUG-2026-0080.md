# BUG-2026-0080: Java construct-matrix decompiler gaps

**Type**: Bug / Improvement
**Status**: IN_PROGRESS (matrix 28→33; more gaps tracked)
**Severity**: HIGH
**Created**: 2026-06-09

## Description
A comprehensive Java 1.0–25 construct matrix (55 self-contained classes, strict decompile→recompile) revealed
27 failing classes (baseline 28/55). See `docs/reports/report-coverage-assurance.md`. Breadth test on 1674 real
JDK 25 classes: 0 crashes, 93.3% marker-clean.

## Solution (batch 1 — cleared C_TextBlocks, C_Arrays, C_AnnotationDecl, C_AnnotationUse)
- **SHARED-1**: `JavaSourceWriter.writeExpressionSimple` dropped invocation/new arguments inside array
  initializer elements (`(/* ... */)`). Delegate those bounded node kinds to the full `writeExpression`.
- **RC-5 multianewarray**: keep the FULL array type on the `NewArrayExpression` (was unwrapping one
  dimension → `new int[][d1][d2]` + `int[][] = <int[]>` type mismatch).
- **Anno 2a**: suppress the implicit `Annotation` superinterface on `@interface` declarations
  (`@interface X extends Annotation` is illegal) — top-level + inner.
- **Anno RC-4**: route the annotation type through `emitRef` so a nested annotation type renders as
  `Outer.Inner` (was the bare `Inner`, unresolved).

### Files Modified
- `service/writer/JavaSourceWriter.java`, `service/converter/ClassFileToJavaSyntaxConverter.java`

### Result
Construct matrix 28/55 → 32/55; corpus holds at 25; DecompilerTest 32/33; regression 159 classes 0 crashes.

## Remaining (tracked)
Lambda/raw-functional-interface generic inference (C_FunctionalInterfaces, C_VarLambdaParams, C_Optional),
return-across-synchronized (C_Concurrency), record canonical-ctor + ternary-arg (C_Records), generic method
signatures + bridge methods (C_RecursiveGenerics, C_Generics), guarded pattern switch (C_PatternSwitch),
unnamed `_` (C_Unnamed), local classes (C_InnerClasses).

## Solution (batch 2-4 — NaN, record ctor, array-foreach type, for-var scope, catch-var recursion)
- B-rec: emit `Double.NaN`/`POSITIVE_INFINITY` (no literal form).
- D-rec: emit the access modifier on a record compact canonical constructor.
- RC-6: array-foreach element type from the array component type.
- For-var used after the loop kept declared outside (empty for-init).
- RC-8: catch-var rename recurses into NewExpression/Ternary/Unary/FieldAccess args.

Matrix 33/55; corpus 25; DecompilerTest 32/33; regression 159 classes 0 crashes.

## Remaining clusters (hard / deferred)
- Lambda/raw-functional-interface + generic-local types: ERASURE-bound without `-g` (parity with JD-Core; with `-g` they recompile). Needs parameterized-type AST support to synthesize from the invokedynamic SAM.
- Switch/control-flow var declaration-hoisting (var assigned in switch cases, used after).
- Guarded pattern switch (`when`), unnamed `_` (Java 22+).
- Anonymous-class capture (`val$`), local classes, finally-unreachable.
