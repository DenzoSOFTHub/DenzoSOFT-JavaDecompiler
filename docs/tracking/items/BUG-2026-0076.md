# BUG-2026-0076: ConstantPool.getUtf8 unguarded cast aborts guarded record-pattern switch decode

**Type**: Bug
**Status**: CLOSED
**Severity**: CRITICAL
**Created**: 2026-06-09
**Resolved**: 2026-06-09

## Description
`J21SwitchPattern.recordPattern` aborted with a DECODE_ERROR at a nested `SwitchBootstraps.typeSwitch`
(opcode 0xBA) under a guarded record pattern.

## Technical Analysis
`ConstantPool.getUtf8(index)` did `return (String) values[index];` with no tag check. A `CONSTANT_Dynamic`
entry holds an `int[]`, so the cast threw `ClassCastException`, aborting the whole method decode.

### Solution Implemented
Guard `getUtf8` to return null unless the tag is `CONSTANT_Utf8` (mirrors `getStringConstant`/`getClassName`).

### Files Modified
- `model/classfile/ConstantPool.java` - tag guard + instanceof guard in getUtf8.

### Test Case
J21SwitchPattern now decodes with 0 DECODE_ERROR markers (verified via corpus harness).
