# BUG-2026-0077: bare assignment of a reused slot left without a declaration

**Type**: Bug
**Status**: CLOSED
**Severity**: CRITICAL
**Created**: 2026-06-09
**Resolved**: 2026-06-09

## Description
`var6 = new HashMap();` was emitted with no declaration ("cannot find symbol"); the slot's owning
declaration had been removed by `ForEachDetector` (it owned a for-each iterator that reused the slot).

### Solution Implemented
New post-pass `promoteUndeclaredAssignments` (run after `ForEachDetector`): collects every declared name
(declarations, for-each/for/catch vars, instanceof pattern bindings) + the method parameters, then promotes
the FIRST bare `v = expr;` of any otherwise-undeclared, non-parameter local to a `Type v = expr;`
declaration. Subsequent assignments stay assignments.

### Files Modified
- `service/converter/ClassFileToJavaSyntaxConverter.java` - post-pass + wiring after ForEachDetector.
