# BUG-2026-0074: Bound instance method reference loses its captured receiver

**Type**: Bug
**Status**: RESOLVED
**Severity**: HIGH
**Created**: 2026-06-08
**Resolved**: 2026-06-08

## Description
`prefix::startsWith` (a bound instance method reference) decompiled to `String::startsWith` — the captured
receiver was dropped, changing an unbound reference's arity.

## Solution Implemented
In the method-reference branch of the invokedynamic decoder, for REF_invokeVirtual(5)/invokeSpecial(7)/
invokeInterface(9) with a captured argument, the receiver (`args.get(0)`) is now passed as the
`MethodReferenceExpression` object (rendered `receiver::method`); the unbound case (`String::length`, zero
captures) is unchanged.

### Files Modified
- `service/converter/ClassFileToJavaSyntaxConverter.java`

### Result
`arg0::startsWith` (was `String::startsWith`).
