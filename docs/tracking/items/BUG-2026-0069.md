# BUG-2026-0069: Local decl/type loss: multidim arrays, ternary-to-declaration, local generics erasure

**Type**: Bug
**Status**: TO_ANALYZE
**Severity**: HIGH
**Created**: 2026-06-08

## Description
Multi-dim array initializers garbled; `var r = b?A:B` collapses to a constant; a re-used slot can emit an assignment with no declaration; local generic types erased. Corpus J10Var, ClassicConstructs.

See `docs/reports/report-decompilation-defect-analysis.md` (defect F10) for full root-cause, file:line and
suggested approach.
