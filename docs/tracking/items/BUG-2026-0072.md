# BUG-2026-0072: Method-reference owner type not imported

**Type**: Bug
**Status**: RESOLVED
**Severity**: MEDIUM
**Created**: 2026-06-08
**Resolved**: 2026-06-08

## Description
`ArrayList::new` decompiled without an `import java.util.ArrayList;` → "cannot find symbol". The import
collector handled `NewExpression` but not `MethodReferenceExpression` (nor array-init values, instanceof
check types, unary/array-access operands).

## Solution Implemented
`collectExprImports` now handles `MethodReferenceExpression` (owner import / receiver recursion),
`ArrayAccessExpression`, `UnaryOperatorExpression`, `InstanceOfExpression`, and recurses `NewArrayExpression`
init values.

### Files Modified
- `service/writer/JavaSourceWriter.java`

### Result
J8Streams 1 -> 0 (fully recompiles); J8Lambdas 3 -> 2.
