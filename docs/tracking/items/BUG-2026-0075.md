# BUG-2026-0075: Spurious `permits` clause on enums with constant bodies

**Type**: Bug
**Status**: RESOLVED
**Severity**: MEDIUM
**Created**: 2026-06-08
**Resolved**: 2026-06-08

## Description
A top-level enum with constant-specific bodies carries a `PermittedSubclasses` attribute (its `Enum$N`
constant classes), so the writer emitted `enum E permits E._1, E._2 { ... }` — illegal.

## Solution Implemented
`writeClass` no longer emits `sealed`/`permits` when the type is an enum or a record.

### Files Modified
- `service/writer/JavaSourceWriter.java`

### Test Case
`DecompilerTest.testEnumConstantBody` asserts the output contains no `permits` and no `abstract enum`.
