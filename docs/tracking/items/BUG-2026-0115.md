# BUG-2026-0115: switch-expression / ternary values consumed by aastore or a stack-carried call argument produce STACK_UNDERFLOW

**Type**: Bug
**Status**: IN_ANALYSIS
**Severity**: MEDIUM (diagnosed, not silent)
**Created**: 2026-09-05
**Source**: `docs/reports/report-java25-plus-audit.md` §BUG-2026-0115 and §2 STACK_UNDERFLOW cluster
analysis (audit of 2026-09-05, v1.10.0 baseline).

## Description
When the value of a switch expression or ternary is consumed by an instruction whose other operands
were pushed BEFORE the switch — `aastore` (array and index already on the stack), or a call argument —
the decode underflows and emits the `STACK_UNDERFLOW` diagnostic.

This was cluster (2) of three in the audit's STACK_UNDERFLOW analysis: **8 of the 16 marker files** in
JDK 25 `java.base`. Cluster (1) was the category-2 `dup` family (BUG-2026-0104, released v1.11.0);
cluster (3) is `ConstantPoolBuilder` pc 164 (invokeinterface after a ternary argument), the same
family as this item.

Evidence, javap-verified in the audit:
- `jdk/internal/classfile/impl/StackMapDecoder.java:75-77` (`initFrameLocals`; javap pc 260-315: each arm does `getstatic ...; goto 315`, and `315: aastore` — array and index were pushed before the switch)
- `AnnotationReader` 910/397, `ClassPrinterImpl` 320-324/1292-1293, `VMSupport` 481-484, `ObjectStreamClass` 88, `keytool/Main` 203, `ParserVerifier` 186, `ConstantPoolBuilder` 164.

## Technical Analysis
The merge block's stack must be seeded from the ARM's exit stack PLUS the pre-switch stack (array,
index). Two mechanisms fall short:
- predecessor exit-stack inheritance (BUG-2026-0051) picks ONE predecessor;
- `tryBuildSwitchExpression` requires a `*return`/store merge, which this shape does not have.

**Not re-verified.** The audit's 16-file / 8-file counts are a v1.10.0 measurement; the current
`java.base` marker census has not been re-run for this item. Re-measure before quoting these numbers
as current.

### Suggested Approach
Generalise the switch-expression producer to ANY merge whose single consumer pops the arm value
(`aastore`, `putfield`, an invoke argument, `athrow`, `areturn`): build the `SwitchExpression` and
substitute it into the consumer using the in-place substitution machinery of BUG-2026-0066. Seed the
merge decode with the switch block's exit stack minus the selector.

- `src/main/java/it/denzosoft/javadecompiler/service/converter/ClassFileToJavaSyntaxConverter.java`
