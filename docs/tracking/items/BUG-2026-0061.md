# BUG-2026-0061: Illegal `abstract` modifier emitted on enums with constant bodies

**Type**: Bug
**Status**: RESOLVED
**Severity**: HIGH
**Created**: 2026-06-08
**Resolved**: 2026-06-08

## Description
An enum with constant-specific bodies is implicitly abstract (ACC_ABSTRACT set); the writer printed
`static abstract enum Op` → javac "modifier abstract not allowed here".

## Solution Implemented
Both the inner-class header and `writeAccessFlags` now suppress `abstract` when ACC_ENUM (0x4000) is set
(mirroring the existing `final`/enum guard).

### Files Modified
- `service/writer/JavaSourceWriter.java`

### Known remaining (separate item)
Enum constant *bodies* (the `Op$1`/`Op$2` anonymous subclasses) are still not inlined into the constants
(`ADD("+") { ... }`); tracked separately as part of defect F12.
