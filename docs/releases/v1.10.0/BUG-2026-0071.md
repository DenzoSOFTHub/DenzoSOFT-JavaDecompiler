## Technical Analysis

Root cause (defect F08): `JavaSourceWriter.writeInnerClass` never read
`JavaSyntaxResult.isSealed()`/`getPermittedSubclasses()` (the PermittedSubclasses attribute
IS parsed by `ClassFileToJavaSyntaxConverter`, line ~189): no `sealed` keyword and no
`permits` clause were ever emitted for nested types, and `non-sealed` was never derived
(there is no access flag for it — it must be inferred from a sealed supertype). Additionally
the top-level path only emitted `sealed` on the `class` branch, so a top-level sealed
*interface* produced an illegal bare `... interface X permits ...` header.

`non-sealed` inference requires knowing that a supertype is sealed. That is only reliable
when the whole permitted hierarchy is in the same compilation unit (nested types). When a
permitted subclass lives in another class file, emitting `sealed ... permits` on the parent
would force a final/sealed/non-sealed modifier on a subclass we are not writing — producing
uncompilable batch output. In that case sealed-ness must be dropped entirely (raw but
compilable).

## Solution Implemented

1. **Unit type index** (`unitTypeIndex`, built in `writeCompilationUnit` via
   `indexUnitTypes`): every type of the compilation unit (top-level + nested, recursive),
   keyed by internal name.
2. **`emitsSealed(result)`**: true iff the type has a PermittedSubclasses attribute, is not
   an enum/record (BUG-2026-0075 guard) and EVERY permitted subclass is in `unitTypeIndex`.
   Used to gate the top-level `sealed` keyword (now on both the interface and class
   branches) and the top-level `permits` clause.
3. **`sealedSubtypeKeyword(inner, printsFinal)`**: per nested type returns
   - `"sealed"` when `emitsSealed(inner)` (its own permits clause is then emitted before
     the opening brace, mirroring the top-level emission, `Outer.Inner` refs via emitRef);
   - `null` for enums/records (implicitly final — no modifier allowed/needed) and for types
     that already print `final` from ACC_FINAL;
   - `"non-sealed"` when some other unit type with `emitsSealed()` permits it;
   - `null` otherwise.
4. `writeInnerClass` prints the keyword after the access-flag modifiers and the permits
   clause after extends/implements.
