# BUG-2026-0060: Interface `default` modifier never emitted

**Type**: Bug
**Status**: RESOLVED
**Severity**: HIGH
**Created**: 2026-06-08
**Resolved**: 2026-06-08

## Description
A `default` interface method (flags = `ACC_PUBLIC` only — there is no ACC bit for `default`) printed as
`public String greet() { ... }` inside an interface → javac "interface abstract methods cannot have body".

## Solution Implemented
`JavaSourceWriter.writeMethod` now emits `default` after the access flags when the owner is an interface
and the method is not abstract, not static, not private and not a constructor.

### Files Modified
- `service/writer/JavaSourceWriter.java`

### Test Case
`DecompilerTest` (existing interface tests + corpus J9Interfaces): default methods now compile.
