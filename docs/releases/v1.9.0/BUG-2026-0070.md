# BUG-2026-0070: Enum constant bodies not inlined into constants

**Type**: Bug
**Status**: RESOLVED
**Resolved**: 2026-06-08
**Severity**: MEDIUM
**Created**: 2026-06-08

## Description
`ADD("+"){ int apply()... }` loses its body; the per-constant anonymous subclass (`Op$1`) is not inlined and a stray abstract method is left. Corpus ClassicConstructs.

See `docs/reports/report-decompilation-defect-analysis.md` (defect F12) for full root-cause, file:line and
suggested approach.

## Solution Implemented
`writeEnumConstantBody` inlines the user methods of each constant's synthetic subclass (`Enum$N`) as the
constant's class body. Wired into both the top-level and inner enum constant emitters. ClassicConstructs
enum now compiles (constants provide the abstract method bodies).
