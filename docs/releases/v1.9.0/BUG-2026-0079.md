# BUG-2026-0079: SWITCH-form record patterns reconstructed (JD pipeline)

**Type**: Bug / Improvement
**Status**: RESOLVED (unguarded); guarded `when` arm deferred (PIECE 4)
**Severity**: HIGH
**Created**: 2026-06-09
**Resolved**: 2026-06-09

## Description
The SWITCH form of Java 21 record patterns (`switch (o) { case Line(Point(int x1,int y1),...) -> ... }`,
`J21RecordPattern.sum`) decompiled to a mangled `while(true){ switch(typeSwitch) }` with arm values displaced.
The legacy path structurally cannot reconstruct it (eager single-pass decode); the JD-Core pipeline can.

## Solution Implemented (4 pieces)
1. **Return tail-duplication** (`cfg/jd/ReturnMergeTailDuplicator.java`, new): a switch-expression's arms all
   `goto` a SHARED `*return` merge which the decode-once pipeline collapses to the first arm's value. Duplicate
   the return-merge per value-producing predecessor so each arm decodes its own return value. Guarded by
   `allPredecessorsAreValueGoto` (else ordinary `if(c) return a; else return b;` collapses).
2. **Dead-guard elimination** (`cfg/jd/ControlFlowGraphMaker.java`, Pass 6): the synthetic always-true guard
   `iconst_1; ifeq L` (L = restart) is turned into a fall-through so the value path connects. Guarded by
   `constOffset == fromOffset` + 4-byte-block (else `instanceof #7`'s trailing `0x07` is misread).
3. **Arm fold** (`transform/TypeSwitchRecordFolder.java`, new + `RecordDeconstructionFolder.foldArm`): folds
   `switch(typeSwitch(s,i)){ case k: T v=(T)s; <decon>; return val; } ... return def;` into
   `return switch(s){ case T(comps) -> val; ...; default -> def; }`. Safe no-op on any unrecognized shape.
4. **Selective activation** (`ClassFileToJavaSyntaxConverter`): route ONLY methods with BOTH a
   `SwitchBootstraps.typeSwitch` and a `new java/lang/MatchException` (record DECONSTRUCTION) to the JD
   pipeline; keep legacy default for everything else. Accept JD only when the fold produced a record-pattern
   switch expression (`foldedRecordPatternSwitch`); otherwise restore the pre-JD decode state
   (`patternSwitchLabels`, `declaredVars`) and fall back to legacy cleanly.

### Files Modified
- `cfg/jd/ReturnMergeTailDuplicator.java` (new), `cfg/jd/ControlFlowGraphMaker.java`
- `transform/TypeSwitchRecordFolder.java` (new), `transform/RecordDeconstructionFolder.java` (foldArm)

### Result
`J21RecordPattern.sum` → `return switch (var2) { case Line(Point(int x,int y), Point(int x,int y)) -> ...;
case Point(int x,int y) -> ...; default -> 0; }`. **J21RecordPattern 19 → 0** (6th corpus class to round-trip).
Corpus total 44 → 25. Legacy path byte-identical (selective activation only touches record-switch methods);
regression 159 classes 0 crashes; DecompilerTest 32/33.

### Residual (deferred, PIECE 4)

desugars to a nested typeSwitch + restart loop; the fold bails and that method stays on legacy (13 errors).
