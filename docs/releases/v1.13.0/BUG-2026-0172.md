## Description

A conditional arm whose stack top is the value the outer condition block left pending (the `this` of `this.f = c ? a : d ? b : e`) does not PRODUCE an arm value: it is a nested ternary carrying the pending receiver through. Taking that stack top as the arm emitted `this.op = this.op == 2 ? 3 : this;`.
