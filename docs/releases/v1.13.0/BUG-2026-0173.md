## Description

An Object-typed value is NOT "no information": nothing proved it has the narrower type (no checkcast), so retyping the local and casting the value can throw ClassCastException where the original did not (MessageFormat.subformat: `Object obj = args[i]; .. obj = args;` became `Object[] obj = (Object[]) args[i]`). Keep the declaration as Object; member accesses on it get their casts at the use site.
