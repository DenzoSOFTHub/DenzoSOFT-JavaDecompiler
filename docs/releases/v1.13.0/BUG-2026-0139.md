## Description

Field post-increment/decrement used as a value. javac compiles `cb[pos++]` to `getstatic pos; dup; iconst_1; iadd; putstatic pos` (instance fields: `aload_0; dup; getfield f; dup_x1; iconst_1; iadd; putfield f`): the OLD value stays on the operand stack while the field is written. The put used to be emitted as the statement `pos += 1;` BEFORE the consumer, whose stack entry is a field READ - so the consumer observed the NEW value: `pos += 1; return cb[pos];` silently read the next element (BufferedReader.read). Recognized by identity: the value being stored is `<X> +/- 1` where X is the very expression object still on top of the stack (the dup copy) and X reads the field being written. The store is folded into that entry as `X++` / `X--`.
