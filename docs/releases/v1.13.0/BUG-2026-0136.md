## Description

The physically last goto of the true region is the if/else merge jump only when it leaves the region forward. A goto whose target lies before falseTarget is internal to the then-body: typically the back-edge of a loop that ends the then-body (`if (c) { a = ..; it = ..; while (it.hasNext()) {..} }`). Taking that back-edge target (the loop header) as the merge made the caller emit the then-body as the negated `if (!c) return;` and resume AT the loop header, silently dropping every statement between the condition and the loop (rt.jar BaseRowSet.notifyCursorMoved lost its event and iterator construction). A goto back to condBlock itself is the back-edge of the loop this conditional heads (Fx3: catch handler `goto header` inside a while(true)). A goto BEFORE the region to an ENCLOSING loop header (`if (c) { a; continue; } b`) still means the then-branch never falls into falseTarget and keeps the old meaning.

Without it `for (x : list) { try { return f(x); } catch (E e) {} } throw ...;` (handler back-edge => while(true)) lost its exit test and became an infinite loop. `if (!c) break; <then>` is equivalent to `if (c) { <then> } else break;`.
