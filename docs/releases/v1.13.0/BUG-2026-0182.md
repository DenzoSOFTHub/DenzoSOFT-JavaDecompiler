## Description

A body of plain assignments (`r = Integer.parseInt(s);`, `v = "y" + in.read();`) is real code: skipping it deleted a genuine `catch (Throwable)` / `finally { in.close(); }` and the output still compiled. Skip only an EMPTY body, or a trivial one whose handler was try-with-resources scaffolding (an addSuppressed call, stripped above) - the javac 9+ shape needs that.
