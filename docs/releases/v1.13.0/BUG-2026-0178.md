## Description

Every decoded constant is a FRESH node. The flow builder matches ternary arm values and merge-stack seeds by object identity; the shared iconst/aconst_null singletons made two unrelated ternaries' `1` the same object, so `sb.append(f() ? 1 : 0).append(g() ? 1 : 0)` came out as `sb.append(1).append(g() ? f() ? 1 : 0 : 0)`.
