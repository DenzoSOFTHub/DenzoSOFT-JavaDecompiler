## Description

Arms that leave the switch only through CONDITIONAL jumps (`case 0: if (d != 0 && d != 1) throw ..; break;` compiles to `if_icmpeq merge` + athrow, no goto) gave no candidate: the switch had no merge, the post-switch code was built inside the first arm (followed by `return`) and the other arms fell through into each other (ConfirmationCallback). Count conditional jump targets at/after the last arm entry, and accept one reached from at least two different arms.
