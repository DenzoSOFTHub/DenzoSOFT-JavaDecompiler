## Description

Import resolution driven by what is actually rendered. The AST walk in collectImports() misses every type reached through a node it does not visit (throw, if/while conditions, switch selectors, synchronized, labels ...), and nothing ever checked two imports for a shared simple name. A dry render now records every type reference that goes through emitRef(); the import block is the union of both, and any simple-name collision is resolved by printing the losing type fully qualified.
