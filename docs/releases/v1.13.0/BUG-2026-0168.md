## Description

The Signature attribute omits synthetic and mandated parameters (enum name/ordinal, outer instance), so it can be shorter than the descriptor. Align it to the descriptor's TAIL instead of indexing it from 0, which shifted every type by the synthetic count (`KnownOIDs(String[] oid, String, String...)`).
