## Description

javac ends a protected range just BEFORE the return instruction of a `return expr;` that closes the try body ([31,43) with areturn at 43), and a return statement is positioned at that instruction. Without lines the return then fell outside the region: with nothing else in the body the group was rejected and the catch clause vanished (`try { return get(x); } catch (IAE e) {}` lost its handler).
