## Description

A compound statement's minimum pc is its first CHILD's: for a loop that is the first body statement, past the header. A loop whose body merely STARTS with the protected code then looked like try-body code and the try was wrapped around the whole loop: the first exception left the loop (`for (..) { try { f(); } catch (E e) {..} print(); }`). A compound joins the try only when its last pc is inside the span too.
