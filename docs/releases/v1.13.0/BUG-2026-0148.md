## Description

`if (!$assertionsDisabled) throw ...` throws whenever assertions are on: the asserted condition is FALSE, so the condition this method returns (later negated) must be TRUE. It returned false, producing `assert !false` (an assert that never fires). Also strip the check from the LEFTMOST conjunct of a longer chain: `!$ad && a && b` parses as `((!$ad && a) && b)`.
