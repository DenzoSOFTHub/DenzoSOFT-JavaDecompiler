## Description

With the synthetic outer parameter dropped from the declaration, its uses in the body must go too: javac's null check `outer.getClass();`, the outer argument it forwards to an inner superclass / sibling constructor (`super(outer, ...)` -> `super(...)`, supplied implicitly), and any other read, which is the enclosing instance `Outer.this`.
