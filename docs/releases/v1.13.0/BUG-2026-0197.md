## Description

Both counters must be dead after the loop: a counter read later is hoisted out by the LocalDeclarationFixer, which demoted ONE of the two declarations and left the illegal mixed init `for (m = .., int n = ..; ..)` (java/lang/Throwable.printEnclosedStackTrace reads m after the loop).
