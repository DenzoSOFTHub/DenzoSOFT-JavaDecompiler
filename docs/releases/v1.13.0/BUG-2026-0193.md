## Description

A web whose own values disagree (Format var = null; switch { case: var = NumberFormat..; case: var = DateFormat..; }) has no single type, but it is still a different variable from a web of another type (an earlier `Format[] var = new Format[n]` in the same slot). Treating "mixed" as "unknown" merged the two and the NumberFormat stores did not compile (java/text/MessageFormat.makeFormat). A mixed web now conflicts with every other web whose type has a different array dimension (without a class hierarchy here, subclasses of one type - Op / Op.CharOp - must not count as a conflict).
