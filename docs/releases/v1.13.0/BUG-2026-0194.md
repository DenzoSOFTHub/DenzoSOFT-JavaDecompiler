## Description

The catch parameter is no longer excluded from splitting. It is a param-def, so its own web always keeps the name; a later reuse of its slot inside the clause (`throw e;` then `e = (ClassNotFoundException) Thread.currentThread().getContextClassLoader()` in com.sun.corba.se.impl.util.Utility.loadClassOfType) is a web of its own and gets a fresh name and its own type.
