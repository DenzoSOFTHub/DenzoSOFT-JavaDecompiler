## Description

The merge point a pattern decides is handed to the caller through lastEffectiveMergePoint, but the if-then/else patterns set it BEFORE building their bodies, and every nested conditional built inside those bodies consumes and resets the same field. The caller then fell back to findMergePoint, landed on an already-visited block and stopped: `if (a == null || !a.equals(b)) { if (dbg) log(); return; } tail();` lost tail() silently (javax.security FileLoginModule.attemptAuthentication). Each level now records its decision in its own frame, published to the caller only when it returns.
