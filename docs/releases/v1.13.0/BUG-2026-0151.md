## Description

The structured-flow builder can lose or misplace part of a method and emit a statement that cannot be reached, a non-void body that can complete normally ("missing return statement") or a `break`/`continue` with no valid target. Nothing checked for these shapes, so they surfaced only as recompilation errors.

## Solution Implemented

New `ReachabilityChecker` applies JLS 14.22 to a structured body and reports exactly those three defect kinds. `ClassFileToJavaSyntaxConverter` runs it on the legacy result and, when it reports a problem, structures the method with the guaranteed `SafeStructurer` (BUG-2026-0152) instead, keeping the safe result only if it is itself clean.
