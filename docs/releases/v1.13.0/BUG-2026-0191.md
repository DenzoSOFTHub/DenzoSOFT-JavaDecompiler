## Description

Slot accesses outside every LocalVariableTable scope. javac emits no LVT entry for its own temporaries (the for-each array/length/index `arr$`/`len$`/`i$`, the iterator, switch-on-string and finally temps) and later reuses their slots for named variables. The flattened slot->name map then gave the temporary the NAME and the TYPE of an unrelated variable of the same slot, merging the two: `setName = name_1.length; setter = 0; while (setter < setName)` with setName a String and setter a Method (com.oracle.webservices.internal.api.message.BasePropertySet). An access at a pc covered by no entry of its slot (with the same store near-miss tolerance as resolveSlotRange) is therefore a variable of its own, named `var<slot>[_k]` and typed from the stored value; a later store that opens a NAMED variable on that slot is a new declaration instead of an assignment to the temporary.
