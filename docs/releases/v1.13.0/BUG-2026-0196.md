## Description

A captured value is written as the enclosing method's expression (`proto`, i.e. the outer local `var6`) inside the inlined anonymous body. Without a LocalVariableTable both scopes name locals by slot, so an inner local `var6` declared in the anonymous method shadowed the captured outer `var6`: the reads meant for the captured String bound to an InetSocketAddress (sun.net.spi.DefaultProxySelector). Inner declarations that collide with a local the captures read are renamed, with their uses.
