## Description

The writer drops `Integer.valueOf(x)` / `Long.valueOf(x)` / ... as implicit autoboxing. It did so for every one-argument `valueOf`, including the parsing overload `Integer.valueOf(String)`, which turned a String into a boxed value without the parse: output that does not compile or means something else.

## Solution Implemented

Only the boxing overload, whose descriptor takes a single primitive (`(I)Ljava/lang/Integer;` and siblings), is simplified; any other `valueOf` is printed as written.
