## Description

Catch parameters are not in scope yet when this runs: record, per OCCURRENCE, the caught type of every read of a catch parameter inside its clause, so `Object e2 = null; .. e2 = e;` within `catch (IOException e)` refines to IOException (`throw e2;` needs a Throwable). Nested clauses are marked after their enclosing one, so the innermost binding of a reused name wins.
