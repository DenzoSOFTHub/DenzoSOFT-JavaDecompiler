## Technical Analysis

Transcribed from the change comments, in progressive order:

- **BUG-2026-0180-1** (`src/main/java/it/denzosoft/javadecompiler/service/converter/cfg/Javac7TwrNormalizer.java:16`): Bytecode pre-pass for the javac 7/8 try-with-resources desugaring.
- **BUG-2026-0180-2** (`src/main/java/it/denzosoft/javadecompiler/service/converter/ClassFileToJavaSyntaxConverter.java:688`): Normalize the javac 7/8 try-with-resources desugaring into a plain try/finally before any decoding (see Javac7TwrNormalizer).
- **BUG-2026-0180-3** (`src/main/java/it/denzosoft/javadecompiler/service/converter/ClassFileToJavaSyntaxConverter.java:2126`): Handler pcs of try/finally regions produced by Javac7TwrNormalizer: the reconstructor folds them into try-with-resources unconditionally.
- **BUG-2026-0180-4** (`src/main/java/it/denzosoft/javadecompiler/service/converter/transform/TryCatchReconstructor.java:57`): Handler pcs of the try/finally regions that Javac7TwrNormalizer produced from a javac 7/8 try-with-resources desugaring. Such a group is a resource try by construction: it must never be dropped as "trivial".
- **BUG-2026-0180-5** (`src/main/java/it/denzosoft/javadecompiler/service/converter/transform/TryCatchReconstructor.java:820`): never for a normalized javac 7/8 resource try
- **BUG-2026-0180-7** (`src/main/java/it/denzosoft/javadecompiler/service/converter/transform/AstLocalRewriter.java:102`): Resources are statements too: a local rename (e.g. a captured variable getting its val$ source name) must reach the try-with-resources header, or the header and the body disagree on the name.
- **BUG-2026-0180-8** (`src/main/java/it/denzosoft/javadecompiler/service/converter/transform/TryCatchReconstructor.java:852`): For a normalized javac 7/8 resource try the resource is exactly the store right before the region: take only that statement (not every earlier assignment of the slot) and make it a declaration with the most precise type available.
- **BUG-2026-0180-9** (`src/main/java/it/denzosoft/javadecompiler/service/converter/transform/TryCatchReconstructor.java:2734`): `x = init` / `T x = init` as a resource declaration. The slot's decoded type can be Object (an alias `R r = other;` without a LocalVariableTable): use the initializer's own type then, since a resource must be declared AutoCloseable or narrower.
- **BUG-2026-0180-10** (`src/main/java/it/denzosoft/javadecompiler/service/converter/transform/DuplicateDeclarationDemoter.java:144`): A resource cannot be demoted to an assignment like other re-declarations: when its name is already declared in an enclosing scope (a method-top pre-declaration of a reused slot), give the resource a fresh name and rename its uses in the try body instead.
