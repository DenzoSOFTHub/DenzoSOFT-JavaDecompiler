## Description

Inline the accessor by substituting the call's arguments into the accessor's own decompiled body (`return arg0.next;`, `arg0.unlink();`, `return Outer.helper(arg0, arg1, arg2);`). The name-only resolution below handles getters/setters with 1-2 arguments and loses the receiver's cast parentheses; it stays as the fallback.
